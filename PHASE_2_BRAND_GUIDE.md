# Phase 2 — BLACKED PUSSY INNERWEAR brand transformation

## Brand identity

**Public name:** BLACKED PUSSY  
**Descriptor:** INNERWEAR · ART AFTER DARK  
**Release:** Halloween Mega Merge V1

The brand name stays exactly as requested. Naked Canvas and Nude Art Studio are not presented as the public brand. Existing file paths, image provenance, app storage keys and Creator integration names remain unchanged where renaming them could break existing user data or functionality.

## Visual direction

- Midnight black: `#100a0e`
- Charcoal/plum panels: `#21161d` and `#2b1a24`
- Deep wine: `#7f3049`
- Muted rose: `#dc9dab`
- Antique gold: `#c9a26b`
- Main text: warm ivory
- Typography: existing Playfair Display + DM Sans pairing

The visual direction is premium gothic/editorial, not a cluttered horror theme. Glows, borders and animation are restrained. The existing light-theme toggle and English/Hinglish copy switch remain in place.

## Changes in this update

- Updated document title, description and browser theme colour.
- Updated age-gate brand copy while retaining the clear 18+ self-attestation warning.
- Updated header monogram, brand name and descriptor.
- Added a Halloween navigation entry.
- Reframed the top hero around the requested innerwear brand.
- Updated the manifesto and footer brand copy.
- Added a separately namespaced `halloween.css`; the existing `styles.css` is not replaced.

## Preservation rules

- Existing gallery, Pose Atlas, AI Creator, Saved Shelf, modals and source/rights notes remain in the page.
- Existing localStorage keys are deliberately not renamed to preserve favourites, theme preference and authorised session flows.
- Existing app JavaScript modules are not replaced.
- New Halloween classes use the `hw-` prefix to minimise CSS collisions.
